# 小攒一笔 · 微信小程序原型

一个记录“本来想花、最后忍住了”的轻量小程序。可记录金额、消费类别和原因，并按日期回看每日省下的钱，也提供微信零钱余额的手动记录展示。

## 导入方式

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本文件夹。
3. AppID 可先使用测试号或选择不使用云服务的模式。
4. 点击编译即可在模拟器中体验。

## 已有功能

- 记录本来想买的东西、估算金额、消费类别和原因
- 汇总今日与本月记录金额
- 通过日期选择器查看每天省下的金额及记录
- 展示连续记录天数
- 手动填写并展示当前微信零钱余额
- 查看记录并删除误记
- 使用本地缓存保存数据，不需要注册或服务器

## 关于微信零钱

微信小程序没有向普通小程序开放读取用户个人微信零钱余额的通用接口。因此余额需要用户手动填写，不能自动同步余额或交易流水。当前余额和记录保存在本机；卸载或清除小程序数据后，数据可能丢失。

记录金额代表“原本计划支出但最终未支出”的估算金额。后续可增加月历、储蓄目标和分类报表。
